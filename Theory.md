# Теоретическое задание — JavaScript / TypeScript
 
## 1. Строгий режим (`"use strict"`)
 
Строгий режим — специальный режим работы JavaScript, который делает часть правил языка более строгими и помогает раньше находить ошибки. При его включении, например:
 
- нельзя случайно создать глобальную переменную без объявления (`x = 5` без `var/let/const` кинет ошибку);
- нельзя иметь два параметра функции с одинаковым именем;
- `this` внутри обычной функции, вызванной без контекста, будет `undefined`, а не глобальный объект.
Сейчас при использовании современных модулей (`import`/`export`) строгий режим включён по умолчанию, отдельно указывать `"use strict"` не нужно.
 
## 2. Переменные: `var`, `let`, `const`
 
- **`var`** — область видимости функции (игнорирует блоки `{}`), значение можно переназначать. Из-за подъёма (hoisting) к переменной можно обратиться до объявления — в этом месте она будет равна `undefined`.
- **`let`** — область видимости блока `{}`, значение можно изменять. В отличие от `var`, обращение к `let` до объявления кинет `ReferenceError` — переменная существует в «мёртвой зоне» (**temporal dead zone**) до момента объявления.
- **`const`** — область видимости блока `{}`, нельзя переназначить другой ссылкой. При этом содержимое объекта или массива, объявленного через `const`, изменять можно (меняется не сама ссылка, а то, на что она указывает). Как и `let`, подвержен temporal dead zone.
**Что когда применять:** по умолчанию используется `const`, `let` — для счётчиков и значений, которые меняются, `var` — практически никогда, считается устаревшим.
 
## 3. Операторы сравнения
 
`==` / `!=` сравнивают значения с приведением типов, а `===` / `!==` сравнивают и значение, и тип, без приведения.
 
```js
'01' == 1   // true — строка "01" приводится к числу 1
'01' === 1  // false — разные типы (string и number)
 
null === undefined // false — разные типы и разные значения
null == undefined  // true — специальное правило нестрогого сравнения:
                   // null и undefined равны друг другу и только друг другу
 
null > 0   // false
null == 0  // false
null >= 0  // true
```
 
При сравнении через `>`, `<`, `>=`, `<=` значение `null` приводится к числу `0`, поэтому `null >= 0` — `true`. Но при `==` действует отдельное правило (см. выше), и `null` не равен `0`.
 
```js
undefined > 0  // false
undefined < 0  // false
undefined == 0 // false
```
 
При числовом сравнении `undefined` превращается в `NaN`, а любое сравнение с `NaN` всегда даёт `false`. Через `==` с числом `0` он тоже не равен.
 
## 4. Функции как значения
 
Да. В JavaScript функции — **объекты первого класса** (first-class citizens): их можно хранить в переменных, передавать как аргументы в другие функции и возвращать как результат работы функции.
 
## 5. Функции-колбэки
 
```js
function confirmAction(question, onConfirm, onCancel) {
  const answer = prompt(`${question} (да/нет)`);
 
  if (answer?.toLowerCase() === "да") {
    onConfirm();
  } else {
    onCancel();
  }
}
 
confirmAction(
  "Вы точно хотите удалить элемент?",
  () => console.log("Элемент удален"),
  () => console.log("Удаление отменено")
);
```
 
## 6. Объекты, методы объектов, `this`
 
`this` — это ссылка на объект, в контексте которого сейчас вызывается функция.
 
**Пример потери `this`:**
 
```js
const user = {
  name: "Ivan",
  sayHello() {
    console.log(this.name);
  }
};
 
const hello = user.sayHello;
hello(); // undefined
```
 
Функция сохранена отдельно от объекта, поэтому вызывается уже не как метод `user`, и `this` внутри неё теряет связь с исходным объектом.
 
**Решение через `bind`:**
 
```js
const hello = user.sayHello.bind(user);
hello(); // Ivan
```
 
**Решение через стрелочную функцию:**
 
```js
setTimeout(() => user.sayHello(), 1000);
```
 
Стрелочная функция не имеет собственного `this` и берёт его из внешнего контекста (там, где определена и где `user` существует).
 
## 7. Планирование: `setTimeout` и `setInterval`
 
- **`setTimeout`** позволяет выполнить функцию один раз через определённое время.
- **`setInterval`** позволяет выполнять функцию через определённый промежуток времени снова и снова.
Указанная задержка — это **минимальное** время до выполнения, а не гарантированное точное: таймер встаёт в очередь и выполнится только после того, как освободится стек вызовов и выполнятся более ранние задачи.
 
Отменяются они соответственно:
 
```js
clearTimeout(timer);
clearInterval(interval);
```
 
**Разница между `setInterval` и рекурсивным `setTimeout`:** при `setInterval` следующий запуск планируется независимо от того, закончился ли предыдущий вызов (вызовы могут накладываться друг на друга, если функция выполняется долго). При рекурсивном `setTimeout` следующий запуск планируется только после завершения текущего — это даёт более предсказуемый и безопасный тайминг.
 
## 8. Что такое TypeScript
 
TypeScript — язык, основанный на JavaScript, добавляющий статическую типизацию. Главное отличие от JS в том, что в TypeScript можно заранее указать типы данных, и компилятор проверит их соответствие ещё до запуска кода. TypeScript нужен в первую очередь для того, чтобы находить ошибки раньше, делать код понятнее и удобнее в поддержке, особенно в больших проектах.
 
## 9. Базовые типы TypeScript
 
- `string` — строка
- `number` — число
- `boolean` — булево значение
- `null` — отсутствие значения
- `undefined` — значение не определено
- `bigint` — целое число произвольной точности
- `symbol` — уникальный и неизменяемый примитив
- `object` — объект
- `array` — массив, например `number[]`
- `tuple` — кортеж с фиксированными типами и порядком элементов
- `any` — фактически отключает проверку типа
- `unknown` — неизвестный тип, безопаснее `any`
- `void` — обычно используется для функций, которые ничего не возвращают
- `never` — тип значения, которое никогда не возникает, например для функции, всегда выбрасывающей ошибку
## 10. Обобщённые типы (Generics)
 
Generics позволяют писать код, который работает с разными типами, но при этом сохраняет информацию о конкретном типе.
 
```ts
function getFirst<T>(items: T[]): T {
  return items[0];
}
 
const number = getFirst([1, 2, 3]);       // number
const name = getFirst(["Ivan", "Alex"]);  // string
```
 
Здесь `T` — это тип, который определяется при вызове функции.
 
```ts
interface Response<T> {
  data: T;
  success: boolean;
}
 
const response: Response<string> = {
  data: "Hello",
  success: true
};
```
 
Одна и та же структура `Response` переиспользуется для разных типов данных.
 
## 11. `type` и `interface`
 
Оба способа позволяют описывать типы объектов, но есть отличия.
 
`interface` можно расширять через `extends`:
 
```ts
interface User {
  name: string;
}
 
interface Admin extends User {
  isAdmin: boolean;
}
```
 
`interface` поддерживает **declaration merging** — если объявить интерфейс с одним и тем же именем несколько раз, TypeScript объединит их в один:
 
```ts
interface User {
  name: string;
}
 
interface User {
  age: number;
}
// итоговый User: { name: string; age: number }
```
 
`type` так делать нельзя — повторное объявление вызовет ошибку. Зато `type` удобен тем, что позволяет описывать не только объекты, но и объединения, пересечения и другие типы:
 
```ts
type Status = "loading" | "success" | "error";
 
type User = {
  name: string;
} & {
  age: number;
};
```
 
## 12. Необязательные свойства
 
Для отдельных свойств используется `?`:
 
```ts
interface User {
  name: string;
  age?: number;
}
```
 
Если нужно сделать необязательными сразу все свойства, используется встроенный тип `Partial`:
 
```ts
type PartialUser = Partial<User>;
```
 
## 13. `Omit`
 
`Omit` позволяет создать новый тип на основе существующего, исключив из него определённые свойства. Это удобно, например, когда объект из базы данных содержит `id`, но при создании нового пользователя `id` передавать не нужно:
 
```ts
interface User {
  id: number;
  name: string;
  email: string;
}
 
type NewUser = Omit<User, "id">;
// { name: string; email: string }
```
 
## 14. Перегрузка функций
 
Да. В TypeScript можно описать несколько вариантов сигнатуры одной функции, а затем написать одну общую реализацию:
 
```ts
function format(value: string): string;
function format(value: number): string;
 
function format(value: string | number): string {
  return String(value);
}
 
format("hello");
format(123);
```
